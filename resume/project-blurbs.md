## 项目① 基于 S7-1200 + FactoryIO 的三工位分拣产线虚拟调试

- **项目背景**：在零硬件条件下，用 TIA Portal V18 + S7-PLCSIM + FactoryIO 复现一条"上料→高度检测→双推缸分拣→产量统计"的自动化产线。
- **我的工作**：独立完成 IO 地址表规划，按 OB1/FB1(ConveyorCtrl)/FB2(SortStepCtrl)/FB3(Counter)/DB1 分层结构编写 LAD+SCL 程序，并用 WinCC Basic 组态主画面/报警/参数三屏。
- **技术亮点**：步标志字顺序控制、光电防抖（TON 200ms）、急停断点续跑、产量误差=0 校验。
- **可量化结果**：连续分拣 ≥20 个工件无卡料，急停恢复后从断点继续，计数误差为 0。（开发中，验收数据待补齐）

## 项目② PLC + 六轴机械臂取放联动工位

- **项目背景**：结合机器人工程专业背景，在 FactoryIO 虚拟场景中用 S7-1200 控制六轴机械臂完成自动取放料。
- **我的工作**：设计 PLC↔机器人 DI/DO 信号交互表（Start/Pick/Place/Gripper × Busy/InPosition/GripperClosed），用 SCL CASE 实现 0→10→20→30→40 步序，并在 HMI 上显示节拍时间。
- **技术亮点**：机器人握手时序、夹爪到位反馈联锁、节拍 ≤8s/循环目标管理；寒假升级 URSim + Modbus TCP（MB_CLIENT）。
- **可量化结果**：连续 10 个取放循环无错位，节拍时间 HMI 可见。（开发中，验收数据待补齐）

## 项目③ C# 上位机 Modbus TCP 数据采集监控

- **项目背景**：为产线 PLC 搭建数据上行通道，实现远程监控、历史存库与配方下发。
- **我的工作**：PLC 侧调用 MB_SERVER（端口 502），C# WinForms(.NET 6) 用 NModbus4/S7.NET 以 1s 周期 ReadHoldingRegisters，LiveCharts2 画趋势曲线，SQLite 存历史数据。
- **技术亮点**：Invoke 切回 UI 线程、WriteMultipleRegisters 远程改配方、catch SocketException 后 3 秒自动重连。
- **可量化结果**：1 秒刷新 50 寄存器，趋势曲线 30 分钟无断点，断线 3 秒内重连。（开发中，验收数据待补齐）

## 项目④ OpenCV 视觉检测 + PLC 分拣联动

- **项目背景**：在分拣产线上叠加机器视觉，按工件颜色与位置自动分流到 3 个料道。
- **我的工作**：Python 3.10 + OpenCV 实现 HSV 红色双区间分割 + findContours + 质心计算，pyModbusTCP 轮询 PLC 拍照触发位 Q1.5 后写回中心 X 坐标（MW300）与类别（MW302）。
- **技术亮点**：红色 HSV 双区间拼接、视觉坐标 ↔ PLC 位置映射、100ms 轮询触发。
- **可量化结果**：10 张测试图识别准确率 ≥95%，连续 20 次分拣无误。（开发中，验收数据待补齐）

## 项目⑤ 威纶通 HMI 组态

- **项目背景**：补齐设备岗标配触摸屏画面能力，离线仿真连 S7-1200。
- **我的工作**：用 EasyBuilder Pro 组态 5 个画面——主画面/手动操作/参数配方/报警记录/趋势曲线；定义故障字 bit0 急停、bit1 气压低、bit2 伺服超时。
- **技术亮点**：Recipe 配方一键下载到 PLC DB、故障位弹窗+蜂鸣+历史翻页、实时+历史趋势。
- **可量化结果**：5 画面离线仿真跑通，故障触发弹窗与历史记录正常，配方切换 PLC 同步。（开发中，验收数据待补齐）
