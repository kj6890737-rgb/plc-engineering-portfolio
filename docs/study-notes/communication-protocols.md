# 工业通信协议学习笔记

> 用途说明：本笔记整理 PLC 校招/项目中最常遇到的 6 类通信协议，重点放在 Modbus RTU/TCP 帧结构、Profinet、EtherCAT、OPC UA、S7 协议，最后附一张学习优先级总表。

## 1. Modbus RTU 帧结构

Modbus RTU 跑在 RS-485 串口上，一帧结构固定为 4 段：

| 段 | 长度 | 含义 |
|---|---|---|
| 站号（Address） | 1 字节 | 0~247，0 为广播 |
| 功能码（Function） | 1 字节 | 决定读/写哪种数据 |
| 数据（Data） | N 字节 | 寄存器地址、数量、写入值等 |
| CRC16 校验 | 2 字节 | 低字节在前、高字节在后，校验整帧 |

**报文示例：主机读从机 1 号站、保持寄存器 40001（地址 0）开始 2 个寄存器：**

| 站号 | 功能码 | 起始地址 H | L | 寄存器数 H | L | CRC 低 | CRC 高 |
|---|---|---|---|---|---|---|---|
| 01 | 03 | 00 | 00 | 00 | 02 | C4 | 0B |

从机返回：`01 03 04 00 0A 00 14  FA 3B`（数据长度 4 字节，值分别为 0x000A=10、0x0014=20）。

> 帧与帧之间靠 ≥3.5 个字符时间的静默间隔分隔，没有起止符。

## 2. Modbus TCP 与 RTU 的区别

| 对比项 | Modbus RTU | Modbus TCP |
|---|---|---|
| 物理层 | RS-485 串口（两线、主从） | 以太网（RJ45、TCP/IP） |
| 端口 | — | TCP 502 |
| 帧头 | 站号 | MBAP 头 7 字节（事务元 + 协议号 0 + 长度 + 单元 ID） |
| 校验 | CRC16 | 由 TCP 保证，帧内无 CRC |
| 拓扑 | 一主多从、最多 247 站 | 以太网交换机，多主多从 |
| 典型场景 | 变频器、仪表、老设备联网 | 上位机/SCADA 直连 PLC |

## 3. 常用功能码表

| 功能码 | 名称 | 操作对象 | 读写 |
|---|---|---|---|
| 01 | 读线圈 | 线圈（位，0xxxx） | 读 |
| 02 | 读离散输入 | 离散输入（位，1xxxx） | 读 |
| 03 ★ | 读保持寄存器 | 保持寄存器（16 位，4xxxx） | 读 |
| 04 | 读输入寄存器 | 输入寄存器（16 位，3xxxx） | 读 |
| 05 | 写单线圈 | 线圈 | 写 |
| 06 ★ | 写单寄存器 | 保持寄存器 | 写 |
| 15（0F） | 写多线圈 | 线圈批量 | 写 |
| 16（10） | 写多寄存器 | 保持寄存器批量 | 写 |

> 03 和 06 是 PLC 项目里用得最多的两条——读/写保持寄存器。

## 4. PROFINET vs Profibus

| 对比项 | Profibus DP | PROFINET |
|---|---|---|
| 物理层 | RS-485 现场总线（双绞线） | 以太网（RJ45/光纤） |
| 速率 | 最高 12 Mbps | 100 Mbps 起步 |
| 实时性 | 周期性过程数据 | RT（软实时）/ IRT（等时同步，硬件级） |
| 设备标识 | 站地址 0~126 | 设备名（Device Name）+ IP |
| 现状 | 老项目仍大量在用，新项目基本淘汰 | 西门子主推，S7-1200/1500 原生支持 |

> RT 用于普通 IO 通信；IRT 用于运动控制（伺服同步、机器人），要求带 IRT 交换芯片。

## 5. EtherCAT

| 要点 | 说明 |
|---|---|
| 拓扑 | 主从结构，一台主站 + 多台从站，线型/树型/环型 |
| 物理层 | 标准以太网帧，但数据在从站"飞速读取"（on-the-fly） |
| 分布式时钟 DC | 所有从站硬件同步，微秒级抖动，适合多轴同步 |
| 典型场景 | 多轴运动控制、半导体、印刷、机器人 |
| 学习优先级 | 比 Profinet 略低，但做机器人/运动控制岗位会被问到 |

## 6. OPC UA

| 要点 | 说明 |
|---|---|
| 定位 | 跨平台、面向服务的工业互联标准，主打"上位机↔厂级↔云端" |
| 特点 | 不只是传寄存器值，而是带"信息建模"（节点+对象+方法），自带安全（签名加密、账号） |
| 与 Modbus 差异 | Modbus 是现场级主从轮询、简单粗暴；OPC UA 是车间到管理层的双向、事件驱动、跨平台 |
| 典型场景 | 产线 SCADA、MES 采集、远程运维、上云 |

> 一句话记忆：Modbus 解决"设备怎么动"，OPC UA 解决"数据怎么被上层用"。

## 7. S7 协议（西门子私有）

| 要点 | 说明 |
|---|---|
| 性质 | 西门子私有协议，跑在 S7 以太网（TCP 102 端口）上 |
| 用途 | 西门子 PLC ↔ 上位机/HMI 读写 DB、M、I、Q |
| 开源库 | C# 生态常用 **S7.NET**（S7.Net NuGet 包），几行代码连 S7-1200/1500 |
| 学习点 | 本仓库 C# 上位机项目即用 S7.NET 与 S7-1200 通信 |

## 8. 协议对比总表

| 协议 | 物理层 | 主要用途 | 学习优先级 |
|---|---|---|---|
| Modbus RTU | RS-485 | 接仪表/变频器，老设备联网 | ★★★★★ 必学 |
| Modbus TCP | 以太网 | 上位机读 PLC 寄存器 | ★★★★★ 必学 |
| S7 协议 | 以太网（102 端口） | C#/HMI 连西门子 PLC | ★★★★★ 本项目必学 |
| PROFINET | 以太网 | PLC ↔ 远程 IO / 伺服 | ★★★★ 西门子方向必学 |
| Profibus DP | RS-485 | 老产线维护 | ★★ 了解即可 |
| EtherCAT | 以太网 | 多轴运动控制 | ★★ 机器人/运动方向再学 |
| OPC UA | 以太网 | 上 MES/上云、跨厂商 | ★★★ 面试常问定位差异 |
