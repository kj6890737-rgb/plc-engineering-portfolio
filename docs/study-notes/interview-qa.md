# PLC 校招笔面试题库（含参考回答要点）

> 用途说明：按"PLC 基础→电气基础→通信→机器人→项目讲解→自我介绍"分类整理，每题给出答题要点，背熟框架即可在面试时展开。题目覆盖自动化设备/PLC 调试岗校招高频考点。

## 一、PLC 基础（6 题）

| # | 题目 | 参考回答要点 |
|---|---|---|
| 1 | 梯形图的执行顺序？ | 从左到右、从上到下逐行扫描；一个扫描周期内全部执行一遍；与继电器电路图"同时动作"不同，梯形图是串行扫描。 |
| 2 | 什么是扫描周期？ | PLC 自诊断→读输入映像→执行用户程序→写输出映像→通信处理，循环一周的时间；典型几 ms~几十 ms。 |
| 3 | PLC 和单片机有什么区别？ | PLC 是为工业现场设计的整机：光电隔离、宽温、抗干扰、标准化 IO、梯形图易维护；单片机是芯片，需自己画板子写程序，成本低但开发周期长。 |
| 4 | I/O 刷新是什么意思？ | 程序执行阶段读的是"输入映像寄存器"里的快照，不是实时引脚；输出也是先写到输出映像，扫描末统一刷新到物理端子。 |
| 5 | 输入映像区和输出映像区有什么用？ | 保证一个扫描周期内程序看到的输入是稳定的，不会中途跳变；提高可靠性，也便于调试。 |
| 6 | 上升沿/下降沿指令（EU/ED、PLS/PLF）什么时候用？ | 按钮按下去只触发一次动作，而不是按住期间每个周期都触发；常用于步进流程、计数触发。 |

## 二、电气基础（10 题）

| # | 题目 | 参考回答要点 |
|---|---|---|
| 7 | 断路器（空气开关）的作用？ | 短路保护 + 过载保护，手动合闸；选型按额定电流 ≥ 计算电流，留出 1.2~1.5 倍余量。 |
| 8 | 接触器的作用？ | 用小电流线圈控制大电流主触点，实现远程/自动启停电机；不能切断短路电流，要和断路器配合。 |
| 9 | 热继电器的作用？ | 检测电机长期过载（双金属片受热弯曲），动作后串在接触器回路断开；不能做短路保护，整定电流调到电机额定电流。 |
| 10 | 中间继电器的作用？ | 扩点数、放大触点容量、把一个信号分成多路；本身不直接带大功率负载。 |
| 11 | 星三角降压启动原理？ | 启动时定子绕组星形接法（相电压 220V）降电流，转速上来后切三角形接法（线电压 380V）全压运行；适合空载/轻载启动的大功率电机。 |
| 12 | PNP 和 NPN 传感器怎么接线？ | PNP：输出高电平（信号 24V），公共端接 0V，漏型输入 PLC 配；NPN：输出低电平，公共端接 24V，源型输入 PLC 配；接线前先看 PLC 输入类型，不能混。 |
| 13 | 伺服和步进有什么区别？ | 步进：开环、成本低、低速扭矩大、高速丢步；伺服：编码器闭环、响应快、精度高、可高速运行、价格贵；运动控制/高精度选伺服。 |
| 14 | 三相异步电机正反转为什么要互锁？ | 正反转接触器若同时吸合会造成三相电源短路；电气互锁：把对方常闭串到自己线圈回路；最好再加上机械互锁按钮。 |
| 15 | 熔断器和断路器区别？ | 熔断器一次性、短路分断快但要换熔芯；断路器可重复用，带过载+短路，但短路分断速度略慢。 |
| 16 | 接触器和继电器区别？ | 接触器主触点容量大（几十~几百 A），专门控制电机；继电器触点小（几 A），用于逻辑中间放大。 |

## 三、通信（5 题）

| # | 题目 | 参考回答要点 |
|---|---|---|
| 17 | 画出 Modbus RTU 一帧结构。 | 站号(1B) + 功能码(1B) + 数据(N B) + CRC16(2B)；举例：读 1 号站保持寄存器 2 个：`01 03 00 00 00 02 C4 0B`。 |
| 18 | Modbus TCP 和 RTU 区别？ | RTU 跑 RS-485、带 CRC16、主从轮询；TCP 跑以太网、端口 502、前面加 7 字节 MBAP 头、靠 TCP 校验不带 CRC。 |
| 19 | PROFINET 和 Profibus 区别？ | Profibus 是 RS-485 现场总线、速度 12M；PROFINET 是以太网、100M、分 RT（普通实时）和 IRT（等时同步用于运动控制）；新设备都用以太网。 |
| 20 | 为什么现场设备还用 Modbus，不直接上 OPC UA？ | Modbus 简单、寄存器模型直观、老仪表/变频器原生支持、成本低；OPC UA 信息建模复杂、开销大，适合车间到管理层，不适合现场高频小数据。 |
| 21 | CRC16 是干什么的？ | 校验整帧有没有传错，接收方重算一遍对比，不一致就丢弃；Modbus RTU 必带，TCP 不需要因为 TCP 自带校验。 |

## 四、机器人（4 题）

| # | 题目 | 参考回答要点 |
|---|---|---|
| 22 | PLC 和六轴机器人之间怎么做 IO 握手？ | PLC 发"允许启动/有料/到位"给机器人 DI，机器人回"忙碌/完成/故障"给 PLC DO；典型握手：PLC 发请求→机器人回忙→动作完回完成→PLC 复位请求。 |
| 23 | 机器人的基坐标、工具坐标、用户坐标有什么区别？ | 基坐标：机器人底座固定世界坐标；工具坐标 TCP：装在法兰末端的工具点，所有运动围绕它；用户坐标：在工作台上建的局部坐标，方便编程。 |
| 24 | 示教器（Teach Pendant）的作用？ | 手动操纵机器人、点动 jog、示教点位、写程序、切自动/手动模式；安全上带三位使能开关。 |
| 25 | DO/DI/AI/AO 在机器人工作站里分别接什么？ | DI/DO 接 PLC 握手信号、夹具夹紧、真空吸盘检测；AI/AO 一般用于传感器模拟量（如压力、位移），机器人本体用得少，主要在 PLC 侧。 |

## 五、项目讲解引导（3 题）

| # | 题目 | 回答框架 |
|---|---|---|
| 26 | "介绍一个你做的项目" | ①一句话背景（什么产线、解决什么问题）→②我负责哪一块（PLC 程序/电气接线/上位机）→③用了什么软硬件（S7-1200 + TIA V18 + FactoryIO + C#）→④遇到的一个难点和怎么解决的→⑤结果指标（节拍、精度）。**不要一上来念代码。** |
| 27 | 项目里遇到的最大难点是什么？怎么解决的？ | STAR 法：Situation 背景→Task 任务→Action 我做了什么（查手册/抓报文/改互锁）→Result 结果。一定要落到具体技术动作，不要说"我努力学习"。 |
| 28 | 你这个项目是仿真还是真机？ | 如实回答：本阶段在 FactoryIO 虚拟环境做逻辑验证，目标是后续上真机；强调"逻辑是真的、协议是真的、思路是可迁移的"，不要包装成已落地项目。 |
