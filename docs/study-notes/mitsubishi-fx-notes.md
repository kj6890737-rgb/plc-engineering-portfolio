# 三菱 FX 系列 PLC 指令速查（GX Works3 / GX Developer）

> 用途说明：本笔记面向三菱 FX 系列（FX3U/FX5U 为主）入门学习，覆盖软元件、基本指令、应用指令、步进 STL、定时器/计数器，标注校招笔试高频考点，供查指令和刷笔试题用。

## 1. 软元件分类表

| 软元件 | 含义 | 编号范围（FX3U 典型） | 说明 |
|---|---|---|---|
| X | 输入继电器 | X000~X267（八进制） | 接按钮/传感器，外部物理输入 |
| Y | 输出继电器 | Y000~Y267（八进制） | 接接触器/指示灯，外部物理输出 |
| M | 辅助继电器（中间继电器） | M0~M3079 | 内部标志位，M0~M499 通用，M500~ 锁存 |
| S | 状态继电器 | S0~S999 | 步进梯形图 STL 的步 |
| T | 定时器 | T0~T255 | 100ms 型 T0~T199，10ms 型 T192~T199 等 |
| C | 计数器 | C0~C255 | 16 位加计数 C0~C199，32 位高速 C235~ |
| D | 数据寄存器 | D0~D7999 | 16 位，D0~D199 通用，D200~ 锁存 |
| K | 常数（十进制） | — | 设定值，如 K10=10 |
| K/H | 常数 | — | K 十进制、H 十六进制，如 H1F |

> 注意：X/Y 编号是八进制（X0~X7，X10~X17，没有 X8、X9），M/D/T/C 是十进制。

## 2. 基本逻辑指令（笔试高频 ★）

| 指令 | 功能 | 梯形图含义 | 典型用途 |
|---|---|---|---|
| LD ★ | 取常开 | 左母线接常开触点 | 一行逻辑起点 |
| LDI ★ | 取常闭 | 左母线接常闭触点 | 停止按钮、急停 |
| AND ★ | 串常开 | 串联一个常开 | 两个条件同时满足 |
| ANI | 串常闭 | 串联一个常闭 | 串入热继、互锁触点 |
| OR ★ | 并常开 | 并联一个常开 | 自保触点并联启动 |
| ORI | 并常闭 | 并联一个常闭 | — |
| OUT ★ | 输出线圈 | 驱动 Y/M/T/C | 输出到 Y0、驱动中间 M0 |
| SET ★ | 置位 | 接通后保持 ON | 运行锁存 |
| RST ★ | 复位 | 置 OFF / 清零当前值 | 复位计数器、复位报警 |
| PLS | 上升沿微分 | 输入接通瞬间输出一个扫描周期 | 按钮按一下走一步 |
| PLF | 下降沿微分 | 输入断开瞬间输出一个扫描周期 | 按钮松触发动作 |

**典型启保停电路：**
```
LD   X000      // 启动按钮
OR   M0        // 自保
ANI  X001      // 停止按钮（常闭）
OUT  M0
LD   M0
OUT  Y000      // 输出到电机
```

## 3. 应用指令（功能指令）

| 指令 | 功能 | 写法示例 | 典型用途 |
|---|---|---|---|
| MOV ★ | 传送 | `MOV K100 D0` | 把常数 100 写入 D0 |
| ADD | 加法 | `ADD D0 D1 D2` | D0+D1→D2 |
| SUB | 减法 | `SUB D0 D1 D2` | D0-D1→D2 |
| CMP ★ | 比较 | `CMP D0 K50 M0` | D0 与 K50 比，结果影响 M0/M1/M2 |
| INC | 加 1 | `INC D0` | 每来一脉冲 D0+1 |
| DEC | 减 1 | `DEC D0` | 反向计数 |

> CMP 用法：`CMP S1 S2 D` —— S1>S2 时 D 置 1，S1=S2 时 D+1 置 1，S1<S2 时 D+2 置 1。

## 4. 步进梯形图 STL / RET（SFC 思路）

| 指令 | 作用 | 典型用途 |
|---|---|---|
| STL ★ | 步进接点 | 激活状态 S，进入该步执行其负载 |
| RET ★ | 步进返回 | 一系列 STL 结束后回到左母线 |

**思路：** 把工序拆成 S0（初始步）→ S20 → S21 → S22 … 每一步做一件事，转移条件满足就退出当前步、激活下一步，本质就是 SFC 顺序功能图。适合分拣线、机械手、灌装这类顺序流程。

```
STL  S0        // 初始步
LD   M8002     // 上电脉冲
SET  S0
STL  S20       // 第 1 步：推料缸伸出
OUT  Y000
LD   X000      // 到位信号
SET  S21       // 转移到下一步
STL  S21       // 第 2 步：夹紧
OUT  Y001
...
RET            // 步进结束
```

## 5. 定时器 T 与计数器 C 用法

| 元件 | 设定方式 | 时间/计数单位 | 示例 |
|---|---|---|---|
| T0（100ms 型） | `OUT T0 K50` | 100ms × 50 = 5s | 启动后延时 5s |
| T192（100ms 积算型） | `OUT T192 K30` | 断电也保持，累计到 3s | 长延时累计 |
| C0（16 位加计数） | `OUT C0 K10` | 计 10 个脉冲触点动作 | 流水线数 10 个工件 |

> K 后面的数字是"倍率"，不是秒也不是毫秒，要乘上元件本身的时基。

## 6. GX Works3 与 GX Developer 区别（一句话）

> GX Works3 是三菱新一代编程软件（对应 FX5U/iQ-R），支持结构化文本、标签编程和仿真；GX Developer 是老软件（对应 FX3U 及以前），以软元件地址编程为主——新学 FX5U 用 Works3，维护老设备才会碰到 Developer。

## 7. 校招笔试高频考点（★ 标记）

> 下列指令在校招笔试题中出现频率最高，必须能手画梯形图：
> **LD / LDI / AND / ANI / OR / ORI / OUT / SET / RST / MOV / CMP / STL / RET**
> 常考题型：①画电机启保停；②画星三角降压启动主电路+控制梯形图；③用 STL 写一个 3 步分拣流程；④解释 PLS/PLF 区别；⑤MOV K0 D0 是什么意思。
