# 西门子 S7-1200 / TIA Portal V18 指令速查

> 用途说明：本笔记面向 S7-1200 + TIA Portal V18 入门学习，按"位逻辑→定时器→计数器→DB→传送比较→SCL→组织块"顺序整理，每条指令附典型用途，供写程序和笔试时快速查阅。

## 1. 位逻辑指令

| 指令（LAD/FBD） | 助记符 STL | 含义 | 典型用途 |
|---|---|---|---|
| 常开触点 `| |` | A（And） | 位为 1 时导通 | 启动按钮 I0.0、传感器到位信号 |
| 常闭触点 `|/|` | AN（And Not） | 位为 0 时导通 | 停止按钮 I0.1、急闭、热继常闭 |
| 输出线圈 `( )` | = （输出） | 把 RLO 写入位 | 接触器线圈 Q0.0、中间标志 M0.0 |
| 置位线圈 `( S )` | S | 条件满足后置 1 并保持 | 运行状态自锁、报警锁存 |
| 复位线圈 `( R )` | R | 条件满足后置 0 | 故障复位、停止锁存 |
| SR 触发器（复优） | SR | 置位/复位双输入，复位优先 | 急停同时按下时优先复位，安全回路 |
| RS 触发器（置优） | RS | 置位/复位双输入，置位优先 | 报警发生时优先置位，提示操作员 |

> 要点：SR 与 RS 的区别在"两个信号同时有效时谁胜出"——SR 是 Reset 优先，RS 是 Set 优先。

## 2. 定时器（IEC 定时器，S7-1200 默认）

| 指令 | 名称 | 工作方式 | 典型用途 |
|---|---|---|---|
| TON | 接通延时 | IN 上升沿后，延时 PT 时间 Q 才变 1 | 电机启动后延时 5s 再开风扇、上电延时 |
| TOF | 断开延时 | IN 下降沿后，延时 PT 时间 Q 才变 0 | 停机后风扇再吹 30s（散热）、照明延时关 |
| TP | 脉冲定时器 | IN 触发后 Q 固定输出 PT 宽度脉冲 | 触发一个固定时长的提示音/气吹 |

**IEC 定时器 vs 旧式 S5 定时器：**

| 对比项 | IEC 定时器（TON/TOF/TP） | 旧式 S5 定时器（S_ODT 等） |
|---|---|---|
| 存储方式 | 背景 DB（每个定时器一个 DB，自动生成） | 占用 CPU 内置定时器区 T0~T65535 |
| 数量 | 仅受内存限制，可建几百个 | 数量固定（与 CPU 型号有关） |
| 时间格式 | Time（T#5S） | S5Time（S5T#5S） |
| 推荐度 | S7-1200/1500 主推 | 仅兼容老项目时使用 |

> 注意：S7-1200 只支持 IEC 定时器，S5 定时器是 S7-300/400 时代的概念，新工程不要再用。

## 3. 计数器

| 指令 | 名称 | 输入 | 典型用途 |
|---|---|---|---|
| CTU | 加计数 | CU 上升沿加 1，CV≥PV 时 Q=1 | 流水线计数、产量统计 |
| CTD | 减计数 | CD 上升沿减 1，CV≤0 时 Q=1 | 配料桶数到料提醒 |
| CTUD | 加减双向 | CU/CD 双输入 | 料仓出入库净计数 |

> 计数器同样以背景 DB 形式存在，PV（设定值）和 CV（当前值）都是 Int 类型。

## 4. 数据块 DB 与寻址方式

### 4.1 绝对寻址 vs 符号寻址

| 寻址方式 | 写法示例 | 说明 |
|---|---|---|
| 绝对寻址 | I0.0、Q0.0、MW100、DB1.DBD0 | 直接按内存地址写，可读性差 |
| 符号寻址 | Start_Button、Motor_Run、Data_Max | 在 PLC 变量表里起名，程序里写名字 |

**推荐：** TIA Portal 里一律用符号寻址，绝对地址只在调试监控时看。

### 4.2 地址宽度表示法

| 写法 | 宽度 | 示例含义 |
|---|---|---|
| I0.0 / Q0.1 / M0.0 | 位（1 bit） | 第 0 字节第 0 位 |
| MB0 / QB4 | 字节（8 bit） | Memory Byte 0 |
| MW10 | 字（16 bit） | 从 MB10、MB11 组成的 16 位字 |
| MD20 | 双字（32 bit） | MB20~MB23 共 4 字节 |
| DB1.DBD0 | DB1 中偏移 0 开始的双字 | 数据块里的 32 位数据 |

> 对齐提醒：MW10 与 MW12 会共享 MB11/MB12 边界，定义变量时注意不要重叠（TIA 会自动告警）。

## 5. 传送与比较指令

| 指令 | 功能 | 典型用途 |
|---|---|---|
| MOVE | 把 IN 端值复制到 OUT 端 | 上电时把初始参数（如速度 500）写入 DB |
| CMP == / <> / > / < / >= / <= | 比较两个数值 | 当压力 > 设定值时报警、料位到下限补料 |

## 6. SCL 语言基础

SCL 是类 PASCAL 的结构化文本语言，适合做数据处理、复杂逻辑；LAD 适合联锁。

### 6.1 变量声明（在块接口区）

```pascal
VAR
    Count : Int := 0;        // 静态变量，初值 0
    Speed : Real := 50.0;
    bRun  : Bool := FALSE;
END_VAR
```

### 6.2 常用控制结构

| 结构 | 写法示例 | 典型用途 |
|---|---|---|
| IF / ELSIF / ELSE | `IF bRun THEN ... ELSIF ... ELSE ... END_IF;` | 多分支状态判断 |
| CASE | `CASE step OF 1: ...; 2: ...; ELSE ...; END_CASE;` | 步进流程、状态机 |
| FOR | `FOR i := 1 TO 10 DO ... ; END_FOR;` | 批量处理数组 |
| WHILE | `WHILE i < 10 DO ... ; END_WHILE;` | 不确定次数循环（注意别死循环） |

## 7. 组织块 OB 说明

| OB 编号 | 名称 | 触发时机 | 典型用途 |
|---|---|---|---|
| OB1 | 主循环 OB | 不断循环执行 | 写主逻辑（绝大多数程序在这里） |
| OB100 | 启动 OB | PLC 从 STOP→RUN 时执行一次 | 初始化参数、复位标志位 |
| OB82 | 诊断中断 OB | 模块故障/传感器断线时触发 | 记录故障时间、点亮报警灯 |
| OB35 | 循环中断 OB（默认可设 100ms） | 按固定周期中断 OB1 | 做 PID 调节、定时采样 |

> 扫描周期 = OB1 从开始执行到下一次再开始的时间；OB35 保证定时任务不被长逻辑拖累。
