## 一、市场事实（来自岗位调研，详见报告）

### 校招硬门槛 vs 加分项（基于 2026 年 8–9 月在招校招 JD 归纳）

| 要求项 | 校招定位 | 说明 |
|---|---|---|
| 电气/自动化/机电/**机器人工程**相关专业 | **硬门槛** | 你的专业已达标（多个 JD 明确列入机器人工程） |
| 学过至少一种主流 PLC（西门子/三菱/欧姆龙）+ 基础梯形图 | **硬门槛** | 现在开始学，两周内达标 |
| 了解工业通信协议（Profinet/Modbus） | 硬门槛（基础了解） | 做项目①③自然覆盖 |
| 电气识图能力 | 硬门槛 | 学 EPLAN 前先掌握识图 |
| 能适应车间现场/出差/加班 | 硬门槛（软条件） | 面试表达意愿 |
| 低压电工证 | **现场岗近乎硬门槛** | 12 月报名，1 月考 |
| C#/Python、视觉、机器人、MES/SCADA | 加分项 | 项目②③④正是打这个 |
| 西门子/三菱官方认证 | 加分项，非硬门槛 | 优先级低于项目 |

## 二、策略总纲

1. **主学西门子 S7-1200 + TIA Portal，副学三菱 FX/GX Works3**（株洲中车系、长沙工程机械、新能源产线主流为西门子；中小 OEM 笔试大量考三菱 FX 指令）。
2. **5 个项目按 P0/P1/P2 排序**：P0（10 月底前）做产线仿真 + 机器人联动，P1（12 月底）上位机 + 视觉，P2（寒假）HMI。
3. **前 6 周零硬件全仿真**，11 月底视预算买二手 PLC（500–900 元）补真机手感。
4. **毕设选题复用项目①**（"基于 S7-1200 的自动化分拣工作站虚拟调试"），一鱼两吃。
5. **证书：低压电工证必考**（12 月报名、1 月考），西门子认证视情况再定。

## 五、笔面试准备节奏

- **10 月**：PLC 基础语法（西门子位逻辑/TON/CTU/MOVE；三菱 LD/OUT/MOV/SET/RST/STL）
- **11 月上**：通信协议（Modbus RTU vs TCP 帧结构、Profinet vs Profibus、OPC UA、S7 协议）
- **11 月下**：电气基础（断路器/接触器/热继电器选型、星三角、伺服 vs 步进、PNP vs NPN）
- **12 月**：项目讲解稿（每个项目 3 分钟版 + 5 分钟版 + 追问预案）
- **1–2 月**：牛客网刷题 + 面试复盘

**面试自我介绍模板**：
"我是机器人工程专业，自己用 S7-1200 + FactoryIO 做过一套虚拟分拣产线，里面集成了一个六轴机械臂取放工位，还写了 C# 上位机采集数据存 SQLite。"——一句话打出三个差异化点。
