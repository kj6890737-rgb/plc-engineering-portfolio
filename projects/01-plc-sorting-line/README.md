## 2. 场景设定

FactoryIO 场景：**上料传送带 → 进料光电检测 → 高度传感器区分高/矮工件 → 两个推缸分别推入高料仓/矮料仓 → 计数统计**。

- 工件从传送带左端连续上料；
- 进料光电（I0.3）检测到工件进入；
- 工件走到分拣位光电（I0.4）停下，高度传感器（I0.5）判定高件/矮件；
- 高件由推缸 1（Q0.1）推入料仓 1，矮件由推缸 2（Q0.2）推入料仓 2；
- 本班总产量、高件数、矮件数分别计数并送 HMI 显示。

| PLC 地址 | 方向 | 物理含义 |
|---|---|---|
| I0.0 | 输入 | 启动按钮 |

| I0.2 | 输入 | 急停（常闭） |
| I0.3 | 输入 | 进料光电传感器 |
| I0.4 | 输入 | 分拣位光电传感器 |
| I0.5 | 输入 | 高度传感器（1=高件，0=矮件） |
| Q0.0 | 输出 | 传送带运行 |
| Q0.1 | 输出 | 推缸 1（高件 → 料仓 1） |

| Q0.3 | 输出 | 报警灯 |
| MW100 | 内部字 | 本班总产量 |
| MW102 | 内部字 | 高件数 |
| MW104 | 内部字 | 矮件数 |
| MW110 | 内部字 | 分拣延时参数（单位 ms，HMI 可改） |

## 4. 程序结构

| 块 | 名称 | 职责 |
|---|---|---|
| OB1 | Main | 循环调用各 FB，组织整个产线流程 |
| FB1 | ConveyorCtrl | 传送带启停 + 光电防抖（TON 200 ms） |
| FB2 | SortStepCtrl | 顺序步序控制，步标志字 M20.0~M20.3：待机 → 输送 → 定位 → 分拣 |
| FB3 | Counter | CTU 分别计数高件/矮件/总产量 |
| DB1 | Data | 存放产量、班次号、报警字、配方参数 |

## 5. SCL 步序关键逻辑片段

```pascal
// FB2 "SortStepCtrl" 片段：定位到位后按高度选择推缸
IF #Step = 2 AND "Sensor_Done" THEN
    #Step := 3;                       // 进入分拣步
    IF "Height_Sensor" THEN
        "High_Push" := TRUE;           // 高件：推缸 1 动作
    ELSE
        "Low_Push" := TRUE;            // 矮件：推缸 2 动作
    END_IF;
END_IF;

// 推缸到位（磁性开关反馈）后复位输出并清零步
IF #Step = 3 AND "Push_Done" THEN
    "High_Push" := FALSE;
    "Low_Push"  := FALSE;
    #Step := 0;                       // 回到待机，等待下一件
END_IF;
```
