# 项目⑤ 威纶通 HMI 组态 🚧 开发中

> 一句话定位：补齐设备岗标配技能——用威纶通 EasyBuilder Pro 组态 5 个标准画面（主画面 / 手动 / 配方 / 报警 / 趋势），离线仿真连 S7-1200，证明懂"人机交互"而不仅是后台逻辑。

---

## 1. 技术栈

| 类别 | 选型 |
|---|---|
| 组态软件 | 威纶通 EasyBuilder Pro（官方免费下载，weintek.com） |
| 通信协议 | S7 协议（模拟连 S7-1200 PLCSIM） |
| 仿真方式 | EasyBuilder Pro 自带离线仿真（不连真屏） |
| 备选了解 | 昆仑通态 MCGS（国内中小设备厂常用，寒假了解即可） |

---

## 2. 五个画面设计

| # | 画面 | 内容 |
|---|---|---|
| 1 | 主画面 | 设备总图、启动/停止按钮、运行/待机/故障三色灯 |
| 2 | 手动操作画面 | 单个电机点动、气缸手动阀操作 |
| 3 | 参数配方画面 | 3 种产品配方（速度 / 延时 / 目标产量），存在 HMI 内部 Recipe 表，一键下载到 PLC DB |
| 4 | 报警记录画面 | PLC 故障字 DB1.DBW100 按位触发：bit0=急停、bit1=气压低、bit2=伺服超时；历史报警可翻页 |
| 5 | 趋势曲线画面 | 采集 DB1.DBD0（速度）与 DB1.DBD4（温度仿真值），实时曲线 + 历史回看 |

---

## 3. 报警位定义

| 故障字位 | 含义 | HMI 响应 |
|---|---|---|
| bit0 | 急停 | 弹窗 + 蜂鸣 + 主画面故障灯变红 |
| bit1 | 气压低 | 弹窗 + 蜂鸣 + 历史记录 |
| bit2 | 伺服超时 | 弹窗 + 蜂鸣 + 历史记录 |

---

## 4. 可验证完成标准（验收清单）

- [ ] 5 个画面全部能在威纶通 **离线仿真** 里跑通；
- [ ] 触发 PLC 故障位 → HMI **弹窗 + 蜂鸣 + 历史记录可查**；
- [ ] 切换配方后 PLC 侧参数（速度/延时/目标产量）同步变化；
- [ ] 趋势曲线能实时滚动并回看历史；
- [ ] README 包含每个画面截图：（开发完成后补齐：5 张画面截图）。

---

## 5. 无真机替代方案

- EasyBuilder Pro 自带离线仿真，0 成本即可完成全部 5 画面调试；
- 真屏 MT8051iP 约 500–800 元（行情推断），**非必须**；
- PLC 侧由 PLCSIM 仿真，通过 S7 协议与 HMI 仿真通信。
